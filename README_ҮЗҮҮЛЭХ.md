# VET EPI ACADEMY — v1.3 ҮЗҮҮЛЭХ ХУВИЛБАР

## Өөр компьютер дээр шууд үзүүлэх
1. Энэ ZIP-ийг задлана.
2. `START_DEMO.bat` дээр 2 удаа дарна.
3. `index.html` браузерт нээгдэнэ.

## Хүмүүст интернетээр холбоос өгөх
Энэ багцыг статик веб байршуулалтын үйлчилгээ дээр байршуулсны дараа жинхэнэ `https://...` холбоос үүснэ.
`index.html` нь гаднын сервер, database, Node.js зэрэг шаардлагагүй frontend demo тул static hosting-д байрлуулахад бэлэн.

## Чухал
ChatGPT-ийн `sandbox:/...` холбоос нь нийтэд нээлттэй интернетийн холбоос биш. Өөр компьютерт тэр холбоосыг хуулж өгөхөд ажиллахгүй байж болно.
